Fusio-Adapter-Ftp
=====

[Fusio] adapter which provides an action to serve files via FTP as API
response. You can install the adapter with the following steps inside your 
Fusio project:

    composer require fusio/adapter-ftp
    php bin/fusio system:register "Fusio\Adapter\Ftp\Adapter"

[Fusio]: https://www.fusio-project.org/
